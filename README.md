# Yahoo Finance - Quantitative Research Dashboard

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Интерактивный Jupyter Notebook для загрузки и анализа рыночных данных с Yahoo Finance. Проект предоставляет профессиональный инструментарий для факторного анализа, построения эффективной границы, расчёта риск-метрик и визуализации портфельных стратегий.

## 📊 Основные возможности

- **Загрузка реальных данных** с Yahoo Finance (активы: AAPL, MSFT, GOOGL, AMZN, TSLA; факторы: Momentum, Size, Volatility, Liquidity; бенчмарк: S&P 500)
- **Расчёт ключевых метрик**: общая доходность, годовая доходность, волатильность, коэффициент Шарпа, максимальная просадка
- **Интерактивная визуализация** с помощью Plotly:
  - Линейные графики кумулятивной доходности факторов и портфеля
  - Радар-чарт для сравнения риск-метрик стратегии и бенчмарка
  - Тепловая карта корреляций активов
  - Гистограмма распределения месячных доходностей
  - Анализ просадок временных рядов
- **Два типа дашбордов**: базовый (2×2) и расширенный (3×3)
- **Полный цикл количественного анализа**: от загрузки данных до интерактивного исследования

## 🛠️ Установка и зависимости

Для работы требуется Python 3.8+ и следующие библиотеки:


## 🚀 Запуск

1. Клонируйте репозиторий:

```bash

cd Yahoo-Finance
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Запустите Jupyter Notebook:

```bash

```

4. Выполните все ячейки последовательно.

### Содержимое ноутбука

Ноутбук состоит из нескольких ключевых частей:

1. **Введение и описание** (Markdown-ячейка) – объясняет цели и возможности.
2. **Класс `ResearchDashboard`** – инкапсулирует всю логику:
   - `fetch_real_data()` – загрузка данных (активы, факторы, бенчмарк)
   - `add_factor_performance()` – график производительности факторов
   - `add_strategy_returns()` – сравнение стратегии и бенчмарка
   - `add_risk_metrics()` – радар метрик риска
   - `add_correlation_heatmap()` – корреляционная матрица активов
   - `create_performance_table()` – таблица метрик
   - `calculate_max_drawdown()` – расчёт максимальной просадки
   - `create_detailed_dashboard()` – расширенный 3×3 дашборд
3. **Пример использования** – создание дашбордов и вывод результатов.

## 📈 Настройка параметров

Вы можете легко изменить набор активов, период и факторы, отредактировав метод `fetch_real_data()`:

```python
# Изменить период
start = '2018-01-01'
end = '2021-01-01'

# Изменить список акций
assets = ['AAPL', 'MSFT', 'GOOGL', 'AMZN', 'TSLA']

factor_symbols = {
    'Momentum': 'MTUM',

```

## 📊 Результаты

### Базовый дашборд (2×2)

Включает:

- Динамику факторов (кумулятивная доходность)
- Доходность стратегии (средневзвешенная активов) против бенчмарка S&P 500
- Сравнение риск-метрик на радаре
- Тепловую карту корреляций активов

### Расширенный дашборд (3×3)

Добавляет:

- Гистограмму распределения месячных доходностей
- Анализ просадок стратегии и бенчмарка

### Таблица метрик производительности

Пример вывода:

|           | Total Return (%) | Annual Return (%) | Volatility (%) | Sharpe Ratio | Max Drawdown (%) |
| --------- | ---------------- | ----------------- | -------------- | ------------ | ---------------- |
| Strategy  | 245.59           | 47.55             | 30.49          | 1.56         | -13.38           |
| Benchmark | 33.01            | 11.56             | 18.87          | 0.61         | -20.00           |

## 🔍 Используемые данные

- **Активы**: Apple (AAPL), Microsoft (MSFT), Google (GOOGL), Amazon (AMZN), Tesla (TSLA) – месячные данные с 2018 по 2020.
- **Факторы**:
  - Momentum → MTUM (iShares MSCI USA Momentum Factor ETF)
  - Size → VB (Vanguard Small-Cap ETF)
  - Volatility → VIXY (ProShares VIX Short-Term Futures ETF)
  - Liquidity → SPY (SPDR S&P 500 ETF) – как прокси рыночной ликвидности
- **Бенчмарк**: S&P 500 (^GSPC)

Все данные загружаются через `yfinance`.
